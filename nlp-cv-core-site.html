Part 1

NLP 核心

语言模型不是聊天框。核心是 token、语义向量、注意力、对齐、外部知识与行动能力。

Token

文本被切成模型可处理的片段，不等同于自然语言里的“词”。上下文窗口限制的是 token 数。

Embedding

把文本映射到向量空间，用距离表达语义相关性。搜索、推荐、聚类、分类都依赖它。

Transformer

注意力机制让模型在上下文中动态选择重要信息，而不是只看固定窗口。

从续写到助手

预训练让模型会预测下一个 token；指令微调和偏好对齐让模型更愿意按人类目标工作。

RAG 与工具

主流 NLP 产品不是裸模型，而是模型 + 知识库 + 搜索 + 工具 + 权限 + 评估。

Part 2

CV 核心

计算机视觉不只是分类图片，也不是 OpenCV 预处理清单。核心是视觉表示、定位分割、图文对齐和动态世界。

Patch

图像被切成 patch，形成类似 token 的序列，再进入 Transformer 或混合视觉骨干。

ViT / Backbone

CNN、ViT、混合架构负责提取视觉特征。高层特征从纹理走向对象和关系。

CLIP / VLM

图像和文本共享语义空间后，可以用自然语言检索、分类、问答和推理。

分类整张图是什么？输出类别标签。
检测目标在哪里？输出类别和边界框。
语义分割每个像素属于哪类？输出类别掩膜。
实例分割每个独立对象是谁？输出实例掩膜。
跟踪/动作时间上发生了什么？输出轨迹和动作片段。
Part 3

多模态合流

文本负责表达意图，视觉负责提供证据，模型负责对齐与推理，工具负责行动。

视觉问答

看图、读题、定位证据、生成回答。难点是不能靠数据偏差猜答案。

文档理解

版面、表格、图像和文字一起解析。典型场景是合同、票据、报告、课件。

视觉 Agent

观察屏幕或环境，再调用工具完成任务。重点是权限、验证和失败兜底。

必须讲评估

没有评估闭环，模型能力越强，误用风险越大。

NLP 评估

  • 事实正确性
  • 证据忠实度
  • 拒答与不确定性
  • 偏见、安全、隐私

CV 评估

  • 准确率、mAP、IoU
  • 召回率与误报率
  • 鲁棒性与域迁移
  • FPS、内存、端侧功耗

系统评估

  • 端到端成功率
  • 人工介入率
  • 成本与延迟
  • 漂移监控与失败回放

Memory

带走 8 句话

比记住一堆模型名更重要。

  1. NLP 的入口是 token，CV 的入口是 patch。
  2. Embedding 是语义空间，不是关键词匹配。
  3. Transformer 的核心是上下文注意力。
  4. LLM 不是知识库，RAG 和工具让它接近真实业务。
  5. CV 不只是分类，还包括定位、分割、跟踪和生成。
  6. CLIP / VLM 让图像能被自然语言查询和推理。
  7. SAM 类模型代表可提示、可交互的视觉分割。
  8. 上线看评估闭环，不看 demo 演示效果。
